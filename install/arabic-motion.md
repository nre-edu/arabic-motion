# Skill: arabic-motion

> Arabic-first motion video assembler and guide: the user prepares the script (with voice tags), the narration audio, images or infographics and a style reference (a video, an infographic or a Pinterest image); the skill checks the inputs, analyses the reference style, syncs to the voice and renders an MP4 with RTL-correct Arabic text and sound effects. Use for موشن جرافيك، ركّب الفيديو، فيديو مثل هذا المرجع، ريل من صوري وصوتي، motion graphics from my assets. Not for writing scripts, generating voice or images, posters, or slide decks.

## أمثلة (Examples)
### مثال 1: مستخدم يبدأ من الصفر
**المدخل:** أبي أسوي ريل عن فتح التسجيل، وش أجهز؟

**المخرج المتوقع:** ينشئ المشروع، ثم يعطي قائمة قصيرة: `script.md` بنفس نص الصوت مرقّمًا مع `[تاجات]` و`{صورة N}`، ملف الصوت في `voice/` مع وقفة قصيرة بين المقاطع، الصور مرقّمة في `images/`، المرجع في `reference/` (فيديو أو إنفوجراف أو صورة)، ومؤثراته في `sfx/` إن وُجدت. وينبّه لمراجعة شروط أداة الصوت. ثم ينتظر «جاهز» دون أي تحليل.

### مثال 2: الملفات جاهزة
**المدخل:** جاهز، ركّبه مثل المرجع.

**المخرج المتوقع:** يشغّل `check_inputs.py`؛ يجد `{صورة 4}` بلا ملف، فيقول: «المقطع 3 يطلب صورة 4 وما لقيتها في images/». بعد الإصلاح يقيس المرجع ويوقّت الصوت ويربط الصور: المقطع 2 (4.4 ث، بلا علامة) يأخذ صورتين لأن لقطة المرجع 2.4 ث، والإنفوجراف ينتقل إلى المقطع الذي فيه الرقم. يعرض بطاقة أسلوب قصيرة مع جدول الربط ومصدر كل صورة، ويسأل: «نستعمل ألوانكم أم ألوان المرجع؟».

### مثال 3: طلب يكسر قاعدة العربية
**المدخل:** خلّ النص يطلع حرف حرف مثل المرجع.

**المخرج المتوقع:** يوضح في جملتين أن ظهور الحروف العربية منفصلة يكسر اتصالها، ويقترح ما يعطي نفس الإحساس: كلمة كلمة بسرعة مع tick، أو قناع يكشف السطر من اليمين. ينفّذ ما يختاره المستخدم.

### مثال 4: خارج النطاق
**المدخل:** اكتب لي السكربت وسوّ الصوت بنفسك.

**المخرج المتوقع:** يوضح أن المهارة تركّب مواد المستخدم ولا تكتب ولا تولّد الصوت، حفاظًا على لمسته. يعرض المساعدة في مراجعة سكربته كخدمة منفصلة، ويذكّره بتنسيق `script.md` حين يجهز.

- [ ] تحديد أسلوب الحركة والمقاس والمدة والجودة. ← الأسلوب من المرجع وبطاقة الأسلوب؛ المقاس والمدة والجودة في `request.md`.
- [ ] طلب مزامنة الحركة مع الصوت المعتمد. ← تلقائي.
- [ ] مراجعة عينة قصيرة ثم إرسال التعديلات بتوقيتها. ← اطلب «عينة» فتخرج المهارة أول ~5 ثوانٍ بالصوت. أرسل التعديلات بالوقت (مثل «عند 0:07 الصورة متأخرة») وتحدد المهارة المقطع من `beats.json`.

## ٦. المراجعة والتصدير (معًا)
- [ ] مشاهدة الفيديو كاملًا ومراجعة تزامن الصوت والحركة.
- [ ] مراجعة العربية واتجاهها ووضوحها ووقت قراءتها.
- [ ] فحص جودة الصور وعدم قص النصوص والعناصر.
- [ ] مراجعة وضوح الصوت وتوازن الموسيقى والمؤثرات.
- [ ] تصدير MP4 وفحصه وحفظ النسخة النهائية والمشروع.

المهارة تنفّذ هذه الفحوص داخليًا قبل كل معاينة (الفحص والتسليم [-> appendix: qa-delivery.md])، وأنت تعتمد النتيجة بالمشاهدة والاستماع.

## ملفات التسليم
| في القائمة | في المشروع |
|---|---|
| الصوت النهائي | `voice/` |
| السكربت | `script.md` |
| المواد البصرية | `images/` (+ `brand.md` و`fonts/` إن وُجدت) |
| المرجع | `reference/`: فيديو أو صور (+ `reference/notes.md`) |
| طلب التنفيذ | `request.md` |

**القاعدة الذهبية:** اعتمد الصوت أولًا، ثم اضبط توقيت المشاهد عليه. المهارة لا تبني توقيتًا على صوت غير نهائي، وأي تغيير في الصوت يعيد التوقيت والربط.

## وضع المحادثة
في أداة بلا ملفات ولا أوامر (ChatGPT، Gemini، محادثة Claude.ai) لا يمكن الرندر. تعمل المهارة هناك مرشدًا:
1. تمشي مع المستخدم في الأقسام ١ إلى ٤ قسمًا قسمًا، وتراجع ما يرسله.
2. تراجع تنسيق `script.md` إن لصقه: الترقيم، والتاجات، والعلامات.
3. إن رفع صوره، تقترح ربطها بالمقاطع. وإن استطاعت الأداة مشاهدة المرجع أو لقطاته، تكتب بطاقة أسلوب مبدئية.
4. في القسم ٥ تجهّز له محتوى `request.md` ليأخذ المجلد كاملًا إلى أداة تنفّذ (مثل Claude Code مع هذه المهارة).
5. لا تدّعي أنها أخرجت فيديو، ولا تعطي رابط ملف غير موجود.

# سير العمل: من ملفات المستخدم إلى الفيديو

## تقسيم الأدوار
| المستخدم يجهّز | المهارة تنفّذ |
|---|---|
| السكربت (`script.md`) بنفس نص الصوت وتاجاته | فحص الملفات وتحويل السكربت إلى مقاطع |
| الصوت (`voice/`) من أداة يختارها | قياس توقيت كل مقطع في الصوت |
| الصور والإنفوجراف (`images/`) | ربط الصور بالمقاطع إن لم يحددها، وتحريكها على توقيت الصوت |
| المرجع (`reference/`): فيديو أو صورة أو إنفوجراف | تحليل المرجع وكتابة بطاقة الأسلوب |
| مؤثرات خاصة (`sfx/`) اختياريًا | إكمال المؤثرات الناقصة، الخلط، الإخراج |

المهارة **لا تكتب السكربت ولا تولّد الصوت ولا الصور**. إن طلب المستخدم ذلك، فاقترح عليه أن يجهزه بنفسه ليحافظ على لمسته، وذكّره بالتنسيق في تجهيز الملفات [-> appendix: inputs.md].

## المراحل
### 0. مرشد التجهيز
عند أول طلب: أنشئ المشروع بـ `init_project.py`، ثم أعطِ المستخدم قائمة قصيرة بما يضعه في كل مجلد (من تجهيز الملفات [-> appendix: inputs.md]). لا تبدأ أي تحليل قبل أن يقول إن الملفات جاهزة.

ملاحظات المستخدم الاختيارية تُقرأ قبل كتابة بطاقة الأسلوب: `request.md` (المقاس، المدة، الجودة، طلبات المشاهد)، `brand.md`، `reference/notes.md`، `voice/style-prompt.md`. `check_inputs.py` يذكر ما وُجد منها في `notes`.

### 1. فحص الملفات
`python "<skill>/scripts/check_inputs.py"` من مجلد المشروع.
- `blocking`: ملف ناقص أو صورة مذكورة غير موجودة. أخبر المستخدم بها في سطر لكل واحدة وتوقف.
- `warnings`: تاج غير معروف، علامة غير مفهومة، صور غير مستعملة. اسأل عنها في رسالة واحدة، أو امضِ بافتراض واضح.
- النتيجة `plan/script.json`.

### 2. قياس المرجع
`python "<skill>/scripts/analyze_ref.py"` ثم انظر في ورقتي اللقطات، وفق تحليل المرجع [-> appendix: reference-analysis.md].

### 3. توقيت الصوت
`python "<skill>/scripts/align_voice.py"` يكتب `plan/beats.json`. راجع الجدول الذي يطبعه: مقطع مدته أقل من ثانية أو أطول بكثير من نصه علامة على حد خاطئ. صحّح يدويًا في `beats.json` عند الحاجة. إن طبع `note: voice is ...` فطول الصوت بعيد عن المدة في `request.md`: أخبر المستخدم قبل البناء (القاعدة: الصوت المعتمد هو المرجع، فإما يقبل المدة أو يعدّل الصوت).

### 4. ربط الصور بالمقاطع
`python "<skill>/scripts/link_images.py"` يربط كل صورة بمقطع:
- علامات `{صورة N}` في السكربت تُحترم كما هي.
- المقاطع بلا علامة تأخذ الصور الحرة بترتيب أرقامها، بعدد يناسب مدة المقطع وطول لقطة المرجع (مقطع 6 ث مع لقطة مرجع 2.5 ث يأخذ صورتين).
- ثم **انظر بنفسك** في الصور ونص كل مقطع ولقطات المرجع، وحسّن الاقتراح: صورة الرسم البياني مع الجملة التي فيها الرقم، صورة الافتتاح مع أقوى جملة، مقطع قصير بلا صورة إن كان المرجع يعرض نصًا وحده في مثل موضعه.

### 5. بطاقة الأسلوب والربط ← المراجعة الأولى
اكتب `plan/style-card.md` (الأسلوب + جدول الربط: المقطع، مدته، صوره، ومصدرها: سكربت أو مقترح) واعرضها. هذه أول نقطة موافقة. بعد الموافقة احفظ الربط النهائي للمقاطع التي بلا علامات في `plan/mapping.json` (مثل `{"3": [4, 5], "6": []}`؛ القائمة الفارغة = نص بلا صورة عن قصد)، وأعد `link_images.py`. لا تعدّل `script.md` نفسه.

### 6. البناء ← المراجعة الثانية
1. حوّل البطاقة المعتمدة إلى `plan/style.json` (القالب في `templates/style.example.json`، والحقول في الرندر [-> appendix: rendering.md]).
2. نزّل الخط المحدد بـ `get_font.py`.
3. ولّد ورقة لقطات من المشهد `render/scenes/story.js` وضع بجانبها ورقة المرجع (`shots.jpg` للفيديو، `images.jpg` للصور)، وأرسلهما معًا للمقارنة. هذه ثاني نقطة موافقة، يتخطاها المستخدم إن طلب الفيديو مباشرة.

### 7. المعاينة الكاملة ← المراجعة الثالثة
0. **عينة (اختيارية):** إن طلبها المستخدم أو `request.md`، ارندر أول ~5 ثوانٍ بالصوت (`--to 5`) واخلطها قبل الباقي.
1. جهّز المؤثرات وفق الصوت [-> appendix: sound.md].
2. ارندر بنصف الدقة، ثم اخلط (الصوت يُضاف تلقائيًا من `cues.json`).
3. افحص داخليًا وفق الفحص والتسليم [-> appendix: qa-delivery.md] وأصلح بصمت.
4. أرسل الفيديو مع ملخص لا يتجاوز 5 أسطر.

التعديلات بعدها إصلاحات موجّهة، وكل معاينة جديدة تكون بالصوت. إن أرسل المستخدم تعديلًا بوقت («عند 0:07 الصورة متأخرة») فاطرح `leadIn` وابحث في `beats.json` عن المقطع الذي يحوي ذلك الوقت.

### 8. النسخة النهائية
نفس المشهد بالدقة الكاملة، ثم الخلط والفحص. لا قرارات جديدة.

# تجهيز الملفات (دليل المستخدم)

هذه القائمة تُعطى للمستخدم كما هي تقريبًا، بلغته، قبل أن يبدأ التجهيز.

## 1. السكربت: `script.md`
نفس النص الذي أرسلته لأداة الصوت، بنفس التاجات. سطر لكل مقطع، بترقيم:

```text
1. [excited] هل تعرف أن ٩٠٪ من خريجينا توظفوا خلال سنة؟ {صورة 1} {على الشاشة: ٩٠٪ توظفوا خلال سنة}
2. [calm] لأن برامجنا مبنية مع جهات التوظيف نفسها. {صورة 2}
3. [serious] سجّل الآن قبل اكتمال المقاعد. {صورة 3,4}
```

| الصيغة | المعنى |
|---|---|
| `[تاج]` بأقواس مربعة | تاج الصوت كما في أداة الصوت. يُحذف من الشاشة، ويحدد طابع حركة المقطع |
| `{صورة 2}` أو `{صورة 3,4}` | اختياري: الصورة أو الصور التي تظهر مع المقطع (بأرقامها في `images/`). بدونها تربط المهارة الصور بنفسها |
| `{على الشاشة: ...}` | نص مختصر يظهر بدل الجملة كاملة. بدونه تظهر الجملة كما هي |
| سطر يبدأ بـ `#` | ملاحظة تُتجاهل |

- المقطع الجيد: جملة أو جملتان، فكرة واحدة.
- تعديلات النطق داخل النص (كتابة كلمة بطريقة تساعد الصوت) لا تضر، لكن إن أردت أن تظهر الكلمة بإملائها الصحيح فاكتبها في `{على الشاشة: ...}`.

**طابع الحركة من التاجات:**
| نوع التاج | أمثلة | أثره |
|---|---|---|
| حماس | excited، happy، surprised، حماس | حركة أسرع، كلمات تكبر، مؤثر تأكيد |
| هدوء | calm، soft، whisper، هادئ | حركة أبطأ، ظهور بالتلاشي |
| جدية | serious، confident، dramatic، جدي | نص أكبر، حركة متزنة |
| وقفة | pause، breath، وقفة | يُفضَّل كحد بين مقطعين |
| غير معروف | أي تاج آخر | تسأل المهارة عنه سطرًا واحدًا |

## 2. طلب التنفيذ: `request.md`
ينشئه المشروع بقالب جاهز. عدّل فيه:
- **المقاس:** عمودي / أفقي / مربع.
- **المدة المستهدفة بالثواني:** المهارة تقارنها بطول الصوت وتنبّهك إن ابتعدت بأكثر من 15%.
- **الجودة:** 1080p افتراضيًا.
- **ملاحظات المشاهد:** أي طلب خاص (مشهد يطول، كلمة تُبرز، ختام بالشعار).

## 3. الصوت: `voice/`
- ملف واحد للتعليق النهائي. WAV أفضل، وMP3 مقبول.
- **اترك وقفة قصيرة (نحو ربع ثانية أو أكثر) بين المقاطع**؛ عليها تعتمد المهارة في التقسيم. أداة الصوت تفعل ذلك عادة عند نهاية الجملة.
- بلا موسيقى داخل الملف. الموسيقى، إن وُجدت، ملف منفصل.
- **برومبت الستايل (اختياري):** احفظ وصف النبرة الذي استعملته في أداة الصوت في `voice/style-prompt.md`؛ تقرؤه المهارة لتفهم طابع الفيديو.
- **الرخصة:** راجع شروط أداة الصوت التي تستعملها (مثل Google AI Studio) للاستخدام التجاري والنشر قبل نشر الفيديو. المهارة لا تفترض أنه مسموح.

## 4. الصور: `images/`
- رقم في بداية اسم كل ملف: `1.png`، `02-chart.jpg`، `3-campus.webp`. رقّمها بترتيب ظهورها المتوقع في السكربت؛ إن لم تكتب `{صورة N}` تربطها المهارة بهذا الترتيب وبإيقاع المرجع، ثم تعرض الربط عليك.
- مقاس كبير يكفي الإطار: 1080 بكسل عرضًا على الأقل للفيديو العمودي.
- الإنفوجراف: صدّره بدقة عالية، ويفضَّل بلا هوامش بيضاء زائدة. النص الصغير داخله قد لا يُقرأ على الجوال؛ اكتب أهم رقم في `{على الشاشة: ...}`.
- استعمل فقط صورًا تملكها أو لك حق استعمالها.
- **الهوية (اختياري):** `brand.md` لألوانك (بصيغة #hex) وأسماء خطوطك، وضع ملفات الخطوط غير المجانية التي تملك رخصتها في `fonts/`. إن وُجد يتقدم على ألوان المرجع.

## 5. المرجع: `reference/`
أي واحد مما يلي، أو أكثر من واحد:
- **فيديو** (MP4 أو MOV): يُؤخذ منه الإيقاع والحركة والانتقالات والشكل.
- **صورة أو إنفوجراف أو تصميم من Pinterest** (PNG أو JPG أو WEBP): يُؤخذ منها الشكل، أي الألوان والتكوين وشكل النص والعناصر الرسومية. الصورة لا حركة فيها، فاكتب ما تريده من حركة في `reference/notes.md`، أو تقترحه المهارة.
- **فيديو مع صور:** الحركة من الفيديو، والشكل من الصور.

الرابط وحده لا يكفي، والمهارة لا تنزّل من Pinterest أو غيرها؛ احفظ الملف بنفسك إن كانت شروط المنصة تسمح، أو خذ لقطة شاشة.
- **ملاحظاتك (اختياري):** `reference/notes.md`: ما تريد أخذه (الانتقالات، الإيقاع، طريقة ظهور النص) وما تريد تركه. ملاحظاتك تتقدم على القياس الآلي.
- يفضَّل بنفس اتجاه فيديوك (عمودي أو أفقي).
- يُؤخذ منه **الأسلوب**: الإيقاع، والحركة، والتكوين، والانتقالات، ومواضع المؤثرات. لا تُستعمل صوره أو موسيقاه أو شعاراته في فيديوك.

## 6. المؤثرات (اختياري): `sfx/`
- ملفات قصيرة بأسماء وظائفها: `whoosh.wav`، `pop.wav`، `click.wav`.
- ما ينقص تكمله المهارة من Openverse (مجاني بترخيص مفتوح) أو بتوليد محلي، وتخبرك بما أضافته.

## قبل أن تقول «جاهز»
- [ ] `script.md` مرقّم، وفيه نفس نص الصوت.
- [ ] ملف صوت واحد في `voice/`.
- [ ] كل `{صورة N}` كتبتها لها ملف بنفس الرقم (العلامات اختيارية).
- [ ] مرجع في `reference/`: فيديو، أو صورة أو إنفوجراف، أو الاثنان.
- [ ] `request.md` فيه المقاس والمدة.

القائمة الكاملة بكل مراحلها في التشيك ليست [-> appendix: checklist.md].

# تحليل المرجع وبطاقة الأسلوب

## الهدف
المرجع يحدد **كيف** يُعرض محتوى المستخدم. الناتج بطاقة أسلوب يوافق عليها المستخدم، ثم تتحول إلى أرقام في `plan/style.json`. تُنسخ التقنية، لا العمل الفني.

## أنواع المرجع
| النوع (`kind`) | ما فيه | ما يُؤخذ منه |
|---|---|---|
| `video` | فيديو موشن | الإيقاع، طول اللقطات، الانتقالات، حركة الصور، الافتتاح، الألوان، التكوين، النص |
| `images` | صورة أو أكثر: إنفوجراف، تصميم من Pinterest، لقطات شاشة | الألوان، التكوين، شكل النص وحجمه ومكانه، العناصر الرسومية، أسلوب الإنفوجراف، المقاس |
| `video+images` | الاثنان | الحركة والإيقاع من الفيديو، والشكل البصري من الصور (عند التعارض في الشكل تتقدم الصور، لأن المستخدم أضافها قصدًا) |

## 1. القياس
```bash
python "<skill>/scripts/analyze_ref.py"
```
يكتب في `plan/reference/`:
- `analysis.json`: النوع، المقاس، وأبرز 6 ألوان بنسبها. وللفيديو أيضًا: المدة، أوقات القطعات، عدد اللقطات، طول اللقطة (متوسط، وسيط، أدنى، أعلى)، القطعات لكل 10 ثوانٍ، ومؤشر الحركة داخل اللقطات (رقم نسبي).
- للفيديو: `shots.jpg` (إطار من منتصف كل لقطة، حتى 24) و`opening.jpg` (أول 3 ثوانٍ كل نصف ثانية).
- للصور: `images.jpg` (الصور المرجعية في ورقة واحدة).

إن ظهر عدد قطعات غير منطقي (صفر في فيديو سريع، أو العشرات في فيديو هادئ) فأعد بـ `--threshold 0.2` أو `0.45`.

## مرجع من الصور فقط
الصورة الثابتة لا تحمل حركة ولا إيقاعًا. خذ منها الشكل، وحدد الحركة بهذا الترتيب:
1. **`reference/notes.md`:** ما كتبه المستخدم عن الحركة والانتقالات («انتقالات ناعمة»، «سريع ونشيط»).
2. **إن لم يكتب:** اقترح حركة تناسب طابع الصورة، واكتبها في البطاقة كاقتراح يحتاج موافقة:

| طابع الصورة المرجعية | حركة مقترحة |
|---|---|
| هادئ، مساحات واسعة، ألوان قليلة | `fade` 0.5 ث، `push-in` خفيف (0.04)، نص `fade` |
| جريء، ألوان قوية، خطوط عريضة | `slide` 0.3 ث، نص `pop`، مؤثر pop عند الأرقام |
| إنفوجراف كثيف بالمعلومات | `wipe` 0.4 ث، `fit: contain` بلا حركة تقريبًا (0.02)، نص `wipe` |
| تحريري أو ورقي | `fade` 0.6 ث، `pan` بطيء، نص `rise` |

3. **الإيقاع:** بلا فيديو لا يوجد طول لقطة، فـ `link_images.py` يستعمل 2.5 ث افتراضيًا، أو قيمة `--shot` إن ذكر المستخدم إيقاعًا («كل 3 ثوانٍ صورة»).

عناصر الإنفوجراف أو التصميم المرجعي (أيقونات، إطارات، أشكال، شريط عنوان) تُعاد **رسمًا بالكود بروح مماثلة**، ولا تُقص من صورة المرجع وتُستعمل.

## 2. النظر
قبل النظر اقرأ `reference/notes.md` إن وُجد: ما كتبه المستخدم يتقدم على استنتاجك. وإن وُجد `brand.md` فألوانه وخطوطه تتقدم على ألوان المرجع، ولا تسأل عنها.

افتح أوراق اللقطات الموجودة (`shots.jpg` و`opening.jpg` للفيديو، `images.jpg` للصور) واقرأها بنفسك. القياس لا يرى ما يلي، والبنود الثلاثة الأخيرة للفيديو فقط:
- **التكوين:** هل الصورة تملأ الإطار أم داخل بطاقة؟ أين النص؟ ما حجم الهوامش؟
- **النص:** حجمه مقارنة بالإطار، وزنه، هل في صندوق أم على الصورة مباشرة؟ كم كلمة في الشاشة؟
- **الافتتاح:** ماذا يظهر في أول ثانية؟ نص كبير، صورة، حركة؟
- **الانتقالات:** قارن إطارين متتاليين في `opening.jpg`. تداخل = تلاشٍ، إزاحة = انزلاق، حد حاد = قطع أو مسح.
- **حركة الصورة:** إن تغيّر حجم الصورة بين إطارين من نفس اللقطة فهو تكبير بطيء.
- **المؤثرات:** إن كان للمرجع صوت فاستمع لأماكنها إن أمكن، أو اسأل المستخدم. المهارة لا تحلل صوت المرجع آليًا.

إن لم تستطع تحديد عنصر من اللقطات فاكتبه في البطاقة كسؤال، لا كحقيقة.

## 3. بطاقة الأسلوب: `plan/style-card.md`
اكتبها بالعربية وباختصار، وكل سطر يذكر مصدره (قياس أو ملاحظة):

```text
# بطاقة الأسلوب: <اسم المرجع> (نوعه: فيديو / صور / الاثنان)
الإيقاع: لقطة كل ~2.4 ث (قياس)، القطع على بداية الجملة (ملاحظة)
التكوين: الصورة في بطاقة بزوايا دائرية أعلى الإطار، النص تحتها (ملاحظة)
حركة الصور: تكبير بطيء خفيف داخل اللقطة (ملاحظة)
الانتقالات: انزلاق من اليمين نحو 0.4 ث (ملاحظة)
النص: عريض، 6 إلى 8 كلمات، يظهر كلمة كلمة (ملاحظة)
الألوان: #0f1b2d 41%، #f4b942 12%، ... (قياس) ← نستعمل ألوان المستخدم أم ألوان المرجع؟
الافتتاح: رقم كبير يملأ الشاشة في أول ثانية (ملاحظة)
المؤثرات: whoosh مع كل انتقال، pop عند الأرقام (من سماع المستخدم / غير متحقق)
الخط: أقرب خط مجاني: Cairo 800 (اقتراح)

ربط المقاطع (من link_images.py بعد تحسينك):
| المقطع | المدة | الصور | المصدر | الطابع |
| 1 | 3.1 ث | 1 | سكربت | حماس |
| 2 | 4.4 ث | 2، 3 | مقترح: مقطع طويل ولقطة المرجع 2.4 ث | هدوء |
| 3 | 0.9 ث | بلا صورة | مقترح: المرجع يعرض نصًا وحده في الأسئلة القصيرة | — |
أسئلة: ...
```

اعرضها على المستخدم. ما يعدّله يُكتب في البطاقة و`PROJECT.md`.

## 4. المرجع في ربط الصور
`link_images.py` يأخذ من المرجع **طول اللقطة** (الوسيط) ليقرر كم صورة يحتاج كل مقطع. وتأخذ أنت من لقطاته ما لا يُقاس:
- هل يعرض صورة واحدة طويلة لكل فكرة، أم يقطع بين صور كثيرة؟ إن كان الأول، فاعتمد صورة لكل مقطع حتى لو طال.
- هل توجد لقطات نص وحده (بلا صورة)؟ متى تظهر: في الأسئلة، الأرقام، الخاتمة؟ طبّق ذلك على المقاطع المشابهة.
- هل تأتي الصورة الأقوى في الافتتاح؟ اجعل أقوى صورة للمستخدم مع المقطع الأول.
- الإنفوجراف والرسوم البيانية مكانها مع الجملة التي تذكر الرقم أو المعلومة نفسها.

إن خالف اقتراحك ترتيب أرقام الصور، فاذكر ذلك في البطاقة بسببه.

## 5. من البطاقة إلى `style.json`
| في البطاقة | في `style.json` |
|---|---|
| المقاس من `request.md` (عمودي / أفقي / مربع) | `format`: 1080×1920 / 1920×1080 / 1080×1080، ثم عدّل `image.area` ليناسبه |
| الصورة تملأ الإطار / داخل بطاقة | `image.layout`: `full` / `card`، و`image.area`، و`image.radius` |
| الصورة كاملة بلا قص (إنفوجراف) | `image.fit`: `contain` |
| تكبير / تصغير / حركة جانبية / ثابتة | `image.motion`: `push-in` / `pull-out` / `pan` / `still`، و`image.amount` (0.04 إلى 0.12) |
| قطع / تلاشٍ / انزلاق / مسح | `transition.type`: `cut` / `fade` / `slide` / `wipe`، و`transition.dur` |
| مكان النص | `text.position`: `bottom` / `top` / `center` |
| النص في صندوق | `text.box`: `true` |
| ظهور النص | `text.effect`: `rise` / `fade` / `pop` / `blur` / `wipe`، و`text.stagger` |
| حجم النص | `text.size` (بكسل في إطار 1080 عرضًا) |
| الألوان | `palette` |
| المؤثرات | `sfx.transition`، `sfx.emphasis`، `sfx.text`، `sfx.gain` |
| شريط تقدم | `progressBar` |

الإنفوجراف: استعمل `fit: contain` حتى لا يُقص، وحركة خفيفة (`amount` 0.03 تقريبًا) حتى يبقى مقروءًا.

ما لا تعبّر عنه هذه الحقول (افتتاح خاص، عنصر رسومي متكرر، ختام بشعار) يُضاف بتعديل `render/scenes/story.js` في المشروع، وفق الرندر [-> appendix: rendering.md] والطباعة العربية [-> appendix: arabic-typography.md].

## 6. المقارنة
عند كل مراجعة ضع ورقة لقطات الفيديو بجانب `shots.jpg` (أو `images.jpg` لمرجع من الصور؛ عندها تقارن الشكل والألوان والتكوين فقط). اسأل نفسك: هل الإيقاع والتكوين والحركة من نفس العائلة؟ إن لا، عدّل `style.json` قبل إرسال المعاينة.

# الصوت: التعليق والمؤثرات والخلط

## التعليق الصوتي (من المستخدم)
المستخدم يجهّز التعليق بأداة يختارها ويضعه في `voice/`. المهارة لا تولّد صوتًا ولا تعدّل أداءه.

```bash
python "<skill>/scripts/align_voice.py"
```
- يقيس فترات الصمت في الملف، ويختار منها حدود المقاطع الأقرب لما يتوقعه طول نص كل مقطع، ويكتب `plan/beats.json` (بداية ونهاية كل مقطع بالثواني من بداية الملف).
- يطبع جدولًا: رقم المقطع، البداية، النهاية، المدة، الطابع، أول النص. راجعه: المقطع الأقصر بكثير أو الأطول بكثير من نصه يدل على حد خاطئ.
- إن قال «found N pauses but need M»: جرّب `--min-silence 0.15`، أو `--noise -30` لصوت فيه ضوضاء خلفية، أو اطلب من المستخدم نسخة بوقفات أوضح بين المقاطع.
- التصحيح اليدوي: عدّل `start` و`end` في `beats.json`؛ المشهد يقرأ منه مباشرة.
- التوقيت **تقديري** إلى أن يُرى في المعاينة. قل ذلك للمستخدم.
- إن تغيّر ملف الصوت: أعد `align_voice.py`. لا تبنِ على توقيت صوت قديم.

المشهد `story.js` يضع الصوت بعد `leadIn` ثانية من بداية الفيديو، ويسجّل ذلك في `cues.json`، فيأخذه `mix_audio.py` تلقائيًا بنفس الإزاحة.

## المؤثرات
**ترتيب المصادر:**
1. **مؤثرات المستخدم** في `sfx/` بأسماء وظائفها (`whoosh.wav`، `pop.wav`). لها الأولوية دائمًا.
2. **Openverse** (مجاني): `scripts/fetch_sfx.py`. الافتراضي CC0 وPDM فقط (بلا نسبة). CC BY مسموح بـ `--licence cc0,pdm,by`، ويكتب السكربت سطر النسبة في `sfx/CREDITS.md`.
3. **توليد محلي:** `scripts/synth_sfx.py` يولّد tick وclick وpop وwhoosh وswish وriser وimpact وding بلا إنترنت. لا يكتب فوق ملف موجود، فلا يمس مؤثرات المستخدم.

أخبر المستخدم في سطر بما أضفته من غير ملفاته ومن أين.

```bash
python "<skill>/scripts/fetch_sfx.py" search "whoosh" --max-sec 2
```
```bash
python "<skill>/scripts/fetch_sfx.py" get <id> --name whoosh
```
- ابحث بالإنجليزية: swoosh، whoosh، click، pop، tick، impact، riser، ding، paper، typing.
- النتائج متفاوتة الجودة؛ افحص المدة واطلب من المستخدم الاستماع للمؤثرات المهمة.
- كل تنزيل يُسجَّل في `sfx/sources.json` (المصدر، المؤلف، الرخصة).
- قد تتأخر الواجهة أو تتوقف لبعض الاستعلامات (لوحظ في 2026-10-28). السكربت يعيد المحاولة ثلاث مرات ثم يتوقف برسالة واضحة؛ عندها جرّب كلمة أخرى أو `--limit` أصغر، أو استعمل `synth_sfx.py`، ولا تعطّل المشروع بانتظاره.

## أين توضع المؤثرات
`story.js` يبنيها من `style.json` ومن طابع كل مقطع:
| الحدث | المفتاح في `style.json` | التوقيت |
|---|---|---|
| انتقال بين لقطتين | `sfx.transition` | قبل الانتقال بـ 0.08 ث (ذروة whoosh تأتي متأخرة) |
| مقطع بطابع حماس | `sfx.emphasis` | مع ظهور نصه |
| ظهور نص أي مقطع آخر | `sfx.text` (يفضَّل `null`) | مع ظهور نصه |

اضبطها بحسب المرجع: إن لم يكن فيه مؤثر مع الانتقالات فاجعل `sfx.transition` قيمة `null`. المؤثرات تخدم الصوت ولا تنافسه: `sfx.gain` بين −14 و−8 dB عادة.

صيغة الإشارة لأي مشهد آخر: `{ at: 1.25, sound: 'pop', gain: -6 }`، و`sound` اسم الملف بلا امتداد في `sfx/`.

# الطباعة العربية المتحركة

## لماذا تنكسر العربية في الموشن؟
الحرف العربي يتغير شكله حسب موقعه في الكلمة (أول، وسط، آخر، منفرد). المتصفح يختار الشكل الصحيح عندما يرسم **الكلمة كاملة**. أي تقنية ترسم الحروف منفصلة (تحريك حرف حرف، تباعد حروف، تقسيم النص لـ spans لكل حرف) تُظهر الحروف بأشكالها المنفصلة، فيبدو النص مقطّعًا وغير مقروء.

## القواعد الإلزامية
1. **أصغر وحدة متحركة هي الكلمة.** لا تأثير يعمل على مستوى الحرف أبدًا.
2. **لا تباعد بين الحروف** (`letterSpacing` يبقى `0px`). التمديد المقصود يتم بالكشيدة «ـ» داخل النص، وباعتدال.
3. **الاتجاه من اليمين:** `ctx.direction = 'rtl'`، والكلمات تدخل بترتيب القراءة (من اليمين لليسار)، والأقنعة والمسحات تبدأ من اليمين.
4. **لا تقص النقاط والذيول:** حدود الأقنعة والصناديق تُحسب من مقاييس فعلية لحروف بنقاط عالية وذيول نازلة، مع هامش. الدالة `layout` في `lib/arabic.js` تفعل ذلك.
5. **النص المختلط:** الكلمات اللاتينية المتجاورة («Claude Code») تبقى كتلة واحدة بترتيبها من اليسار، داخل سطر عربي. `tokenize` تجمعها تلقائيًا.
6. **الأرقام:** اختر نظامًا واحدًا للفيديو كله: أرقام عربية مشرقية (١٢٣) عبر `toArabicDigits`، أو غربية (123). لا تخلط. الصفر المشرقي «٠» صغير ويشبه النقطة في الأحجام الصغيرة، فتجنّبه في التسميات الصغيرة.
7. **التشكيل:** أضفه فقط عند الحاجة لرفع اللبس، وتحقق أن الخط يدعمه وأن الحركات لا تُقص.

## الحركات الآمنة
كلها في `drawWords` بالخيار `effect`:

| التأثير | الوصف | متى |
|---|---|---|
| `rise` | الكلمة تصعد قليلًا وتظهر | العناوين، الافتراضي |
| `fade` | ظهور تدريجي | النصوص الطويلة والهادئة |
| `pop` | تكبير من الوسط مع ارتداد خفيف | الكلمات المفتاحية، الأرقام |
| `blur` | من ضبابي إلى حاد | الافتتاحيات السينمائية |
| `wipe` | قناع يكشف الكلمة من اليمين | النصوص الفرعية، القوائم |

حركات أخرى آمنة تبنيها بنفسك: تحريك السطر كاملًا، تغيير لون كلمة (`highlight`)، صندوق يكبر خلف كلمة (`wordBox`)، كتابة سطر بسطر.

ممنوع: الكتابة حرفًا بحرف (typewriter)، تبعثر الحروف، تدوير كل حرف، موجة على الحروف، أي «text splitting» بالحرف.

## التخطيط
- عرض السطر الأقصى نحو 80% من عرض الإطار، وسطران للعنوان كحد أقصى. استعمل `fitSize` لاختيار أكبر حجم يتسع.
- تباعد الأسطر 1.4 إلى 1.6 للعربية (أعلى من اللاتينية بسبب النقاط والذيول).
- المنطقة الآمنة في الفيديو العمودي: اترك نحو 220 بكسل أعلى و360 أسفل لواجهات التطبيقات.
- الحجم الأدنى المقروء على الجوال: نحو 42 بكسل للنص الفرعي و90 للعنوان في إطار 1080 عرضًا.
- ثلاث مستويات نصية كحد أقصى في الإطار الواحد.

# الرندر الحتمي

## الفكرة
كل إطار دالة في الزمن فقط: `draw(ctx, t)`. لا ساعة متصفح، ولا `requestAnimationFrame`، ولا حالة تتراكم من إطار لآخر. لذلك يمكن رندر أي إطار منفردًا، وإعادة الرندر تعطي نفس البكسلات.

المسار: `render.mjs` يشغّل Chromium بلا واجهة عبر Playwright، ويخدم ملفات المشروع من خادم محلي على `127.0.0.1`، ويطلب كل إطار من الصفحة كصورة، ويمررها إلى FFmpeg مباشرة.

## مشهد التركيب: `render/scenes/story.js`
المشهد الأساسي للمهارة. لا يحتاج تعديلًا في أغلب المشاريع؛ يقرأ:
- `plan/beats.json`: المقاطع بتوقيتها في الصوت، والنص، والصور، والطابع.
- `plan/style.json`: الأسلوب كأرقام (القالب في `templates/style.example.json`، والحقول مشروحة في تحليل المرجع [-> appendix: reference-analysis.md]).
- `images/`: صور المستخدم.

ما يفعله:
- يضع الصوت بعد `leadIn` ثانية، وينهي الفيديو بعد آخر مقطع بـ `tail` ثانية.
- كل صورة لقطة؛ المقطع ذو الصورتين يقسم وقته بينهما. المقطع بلا صورة يعرض نصه في الوسط بحجم أكبر.
- المقطع يبقى حتى بداية المقطع التالي، فالوقفات لا تترك فراغًا.
- طابع المقطع يغيّر سرعة ظهور النص ونوعه: حماس أسرع بـ `pop`، هدوء أبطأ بـ `fade`، جدية بنص أكبر.
- الإشارات الصوتية تُبنى من نفس الأوقات، فأي تعديل في `beats.json` يحرك الصورة والمؤثرات معًا.

**متى تعدّل `story.js` في المشروع:** افتتاح خاص من المرجع، عنصر ثابت (شعار في الزاوية، عنوان قسم)، ختام بشعار، أو انتقال غير موجود في الخيارات. أضف الكود في `draw` واقرأ الأوقات من `B.beats` لا من أرقام ثابتة. لا تعدّل نسخة القالب في مجلد المهارة.

## واجهة أي مشهد
```js
export default {
  width: 1080, height: 1920, fps: 30, duration: 8,
  fonts: [{ family: 'Cairo', src: 'fonts/cairo/Cairo-Variable.ttf' }],
  async load() { /* اختياري: يقرأ ملفات الخطة ويضبط المقاس والمدة والخطوط */ },
  cues: () => [{ at: 0.4, sound: 'whoosh', gain: -8 }],
  audio: { voice: { file: 'voice/take.wav', at: 0.4, gain: 0 } },   // اختياري
  setup(ctx, api) { return { /* تخطيطات وصور محمّلة مرة واحدة */ }; },
  draw(ctx, t, api, state) { /* ارسم الإطار عند الثانية t */ },
};
```
- الإحداثيات بمقاس المشهد الكامل حتى في المعاينة بنصف الدقة؛ التحجيم تلقائي.
- `api` يحوي: `width`، `height`، `ease`، `progress`، `lerp`، `clamp`، `mapRange`، `keys`، `spring`، `rng`، و`arabic` (دوال `lib/arabic.js`).
- المسارات نسبية لجذر المشروع.
- `render/scenes/demo.js` مشهد صغير مستقل لاختبار البيئة فقط.

## قواعد الحتمية
1. العشوائية من `rng(seed)` فقط، وتُنشأ في `setup()`. لا `Math.random()`.
2. الجسيمات والفيزياء: احسبها مسبقًا في `setup()` بخطوة ثابتة، ثم اقرأ منها حسب `t`.
3. الحركة من `progress(t, start, dur)` مع دالة تسهيل. `spring()` صيغة مغلقة بلا حالة.
4. الصور تُحمَّل في `setup()` وتُعاد ضمن `state`.
5. داخل `ctx.save()` استعمل `ctx.globalAlpha *= ...` لا `=`، حتى يبقى تلاشي المجموعة الأم فعّالًا.

## الأوامر
من جذر المشروع:

```bash
node render/render.mjs --scene render/scenes/story.js --sheet qa/sheet-v1.png --times 0,1,2.5,4,6,8
```
```bash
node render/render.mjs --scene render/scenes/story.js --stills qa/frame --times 0,1.5
```
```bash
node render/render.mjs --scene render/scenes/story.js --out exports/video-preview-v1.mp4 --scale 0.5 --format jpeg
```
```bash
node render/render.mjs --scene render/scenes/story.js --out exports/video-final.mp4
```

خيارات أخرى: `--from` و`--to` لرندر جزء، `--fps`، `--crf` (الجودة، الافتراضي 18)، `--preset`، `--ffmpeg <path>`. متغيرا البيئة `AM_FFMPEG` و`AM_CHROMIUM` يحددان المسارات إن لم تكن في PATH.

بلا `--times`، ورقة اللقطات تأخذ 6 أوقات موزعة على الفيديو. لورقة تقابل المرجع، استعمل بدايات المقاطع زائد نصف ثانية من `beats.json`.

كل رندر فيديو يكتب بجانبه `<name>.cues.json` (المؤثرات وموضع التعليق)، وهو مدخل `scripts/mix_audio.py`.

## الأداء
- PNG أدق، وJPEG (`--format jpeg`) أسرع؛ استعمل JPEG للمعاينات.
- `ctx.filter = 'blur(...)'` و`shadowBlur` مكلفان؛ استعملهما على عناصر قليلة.
- زمن الرندر على الأجهزة المختلفة: غير مُتحقَّق بقياس منهجي. سجّل زمن أول رندر في `PROJECT.md` لتقدير الباقي.

# التجهيز والمتطلبات

## ما تحتاجه
| الأداة | الحاجة | الغرض |
|---|---|---|
| وكيل بصلاحية ملفات وأوامر (مثل Claude Code) | ضروري للرندر | تشغيل السكربتات على جهاز المستخدم |
| Python 3.9+ | ضروري | سكربتات الفحص والخطوط والصوت (مكتبة قياسية فقط) |
| Node.js 18+ | ضروري | تشغيل `render.mjs` |
| FFmpeg | ضروري | ترميز الفيديو وخلط الصوت |
| Playwright + Chromium | ضروري | رسم الإطارات (يُثبَّت داخل مجلد `render/` في المشروع) |
| اتصال إنترنت | اختياري | تنزيل الخطوط ومؤثرات Openverse |

في واجهات المحادثة بلا وصول للملفات، تعمل المهارة للتخطيط فقط: الموجز، والخطة، وكود المشهد. الرندر يحتاج جهاز المستخدم.

## الفحص أولًا
```bash
python <skill>/scripts/check_env.py
```
يطبع ما هو موجود وما هو ناقص (`missing`)، ولا يثبّت شيئًا. اشرح الناقص للمستخدم بجملة لكل عنصر.

## التثبيت (بإذن المستخدم، عنصرًا عنصرًا)
اطلب الموافقة قبل كل أمر تثبيت، واذكر ما سيُنزَّل وحجمه التقريبي.

**FFmpeg**
- Windows: `winget install --id Gyan.FFmpeg -e` (ثم افتح طرفية جديدة ليظهر في PATH).
- macOS: `brew install ffmpeg`.
- Linux (Debian/Ubuntu): `sudo apt install ffmpeg`.

**Node.js**
- Windows: `winget install --id OpenJS.NodeJS.LTS -e`.
- macOS: `brew install node`.

**Playwright وChromium** (من جذر المشروع، بعد `init_project.py`):
```bash
npm install --prefix render
```
```bash
npx --prefix render playwright install chromium
```
Chromium نحو 150 إلى 200 ميغابايت، ويُحفظ في ذاكرة Playwright المشتركة فيُستعمل لكل المشاريع.

إن كان FFmpeg أو Chromium في مسار غير قياسي: عيّن `AM_FFMPEG` أو `AM_CHROMIUM`.

## تحديد `<skill>`
`<skill>` هو المجلد الذي فيه `SKILL.md` هذا (في Claude Code غالبًا `~/.claude/skills/arabic-motion`). لا تفترض أنه مجلد العمل الحالي. ضع المسارات بين علامتي تنصيص لأن أسماء المجلدات العربية والمسافات شائعة.

- إن ظهرت رسالة `ffmpeg is not recognized` بعد التثبيت، أعد فتح الطرفية أو عيّن `AM_FFMPEG` إلى المسار الكامل لـ `ffmpeg.exe`.
- في PowerShell 5 استعمل `;` بدل `&&` للربط بين الأوامر.

- [ ] المقاس والمعدل والمدة كما في الخطة.
