# استعمال المهارة في ChatGPT وGemini

في أدوات المحادثة لا يمكن إخراج الفيديو (لا ملفات ولا أوامر على جهازك)، فتعمل المهارة **مرشدًا**: تمشي معك في التشيك ليست، وتراجع السكربت والصور والمرجع، وتجهز `request.md`. الإخراج نفسه يتم في Claude Code أو أي أداة لها ملفات وأوامر.

## ChatGPT
**إن كانت المهارات (Skills) متاحة في حسابك:** ارفع [`install/arabic-motion.zip`](../install/arabic-motion.zip). إن رفضها الفحص الأمني لأنها تحتوي كودًا، ارفع [`install/arabic-motion-text-only.zip`](../install/arabic-motion-text-only.zip) (نفس التعليمات بلا سكربتات).

**بدون المهارات، عبر GPT مخصص أو Project:**
1. أنشئ GPT جديدًا أو Project.
2. ارفع [`install/arabic-motion.md`](../install/arabic-motion.md) كملف معرفة (Knowledge). الملف أطول من أن يوضع في خانة التعليمات.
3. الصق في خانة التعليمات النص المختصر أدناه.
4. ارفع أيضًا [`checklist.webp`](checklist.webp) إن أردت أن يعرض الصورة.

## Gemini
1. أنشئ Gem جديدًا.
2. أضف [`install/arabic-motion.md`](../install/arabic-motion.md) كملف معرفة.
3. الصق في التعليمات النص المختصر أدناه.

## النص المختصر للتعليمات
```text
أنت مرشد موشن جرافيك عربي تعمل وفق ملف المعرفة arabic-motion.md.
المستخدم يجهز بنفسه: السكربت (بنفس تاجات الصوت)، والصوت، والصور، والمرجع (فيديو أو إنفوجراف أو صورة).
دورك هنا الإرشاد فقط لأنك لا تملك ملفات ولا أوامر:
1) امشِ معه في التشيك ليست قسمًا قسمًا ولا تعرضها كلها دفعة واحدة.
2) راجع تنسيق script.md: سطر مرقّم لكل مقطع، [تاجات الصوت]، {صورة N}، {على الشاشة: ...}.
3) إن رفع صورًا فاقترح ربطها بالمقاطع، وإن رأيت المرجع أو لقطاته فاكتب بطاقة أسلوب مبدئية.
4) جهّز له محتوى request.md (المقاس، المدة، الجودة، ملاحظات المشاهد).
5) قل بوضوح إن إخراج الفيديو يتم في Claude Code مع هذه المهارة، ولا تدّعِ أنك أخرجت فيديو.
لا تكتب السكربت بدلًا منه ولا تغيّر نصه، والعربية تتحرك كلمة كلمة لا حرفًا حرفًا.
```

## حالة التحقق
لم تُجرَّب هذه الطريقة بعد في ChatGPT ولا Gemini. حدود الطول وقبول الملفات تختلف حسب الخطة والإصدار. إن رُفض ملف، جرّب النسخة النصية بلا كود، أو أبلغ صاحب المستودع.
