# الصوت: التعليق والمؤثرات والخلط

## التعليق الصوتي (من المستخدم)
المستخدم يجهّز التعليق بأداة يختارها ويضعه في `voice/`. المهارة لا تولّد صوتًا ولا تعدّل أداءه.

```bash
python "<skill>/scripts/align_voice.py"
```
- يقيس فترات الصمت في الملف، ويختار منها حدود المقاطع الأقرب لما يتوقعه طول نص كل مقطع، ويكتب `plan/beats.json` (بداية ونهاية كل مقطع بالثواني من بداية الملف).
- يطبع جدولًا: رقم المقطع، البداية، النهاية، المدة، الطابع، أول النص. راجعه: المقطع الأقصر بكثير أو الأطول بكثير من نصه يدل على حد خاطئ.
- إن قال «found N pauses but need M»: جرّب `--min-silence 0.15`، أو `--noise -30` لصوت فيه ضوضاء خلفية، أو اطلب من المستخدم نسخة بوقفات أوضح بين المقاطع.
- التصحيح اليدوي: عدّل `start` و`end` في `beats.json`؛ المشهد يقرأ منه مباشرة.
- التوقيت **تقديري** إلى أن يُرى في المعاينة. قل ذلك للمستخدم.
- إن تغيّر ملف الصوت: أعد `align_voice.py`. لا تبنِ على توقيت صوت قديم.

المشهد `story.js` يضع الصوت بعد `leadIn` ثانية من بداية الفيديو، ويسجّل ذلك في `cues.json`، فيأخذه `mix_audio.py` تلقائيًا بنفس الإزاحة.

## المؤثرات
**ترتيب المصادر:**
1. **مؤثرات المستخدم** في `sfx/` بأسماء وظائفها (`whoosh.wav`، `pop.wav`). لها الأولوية دائمًا.
2. **Openverse** (مجاني): `scripts/fetch_sfx.py`. الافتراضي CC0 وPDM فقط (بلا نسبة). CC BY مسموح بـ `--licence cc0,pdm,by`، ويكتب السكربت سطر النسبة في `sfx/CREDITS.md`.
3. **توليد محلي:** `scripts/synth_sfx.py` يولّد tick وclick وpop وwhoosh وswish وriser وimpact وding بلا إنترنت. لا يكتب فوق ملف موجود، فلا يمس مؤثرات المستخدم.

أخبر المستخدم في سطر بما أضفته من غير ملفاته ومن أين.

```bash
python "<skill>/scripts/fetch_sfx.py" search "whoosh" --max-sec 2
```
```bash
python "<skill>/scripts/fetch_sfx.py" get <id> --name whoosh
```
- ابحث بالإنجليزية: swoosh، whoosh، click، pop، tick، impact، riser، ding، paper، typing.
- النتائج متفاوتة الجودة؛ افحص المدة واطلب من المستخدم الاستماع للمؤثرات المهمة.
- كل تنزيل يُسجَّل في `sfx/sources.json` (المصدر، المؤلف، الرخصة).
- قد تتأخر الواجهة أو تتوقف للاستعلامات غير المخزّنة لديها، وتجيب فورًا عن الشائعة منها (لوحظ في 2026-10-28)؛ الكلمات الإنجليزية الشائعة (whoosh، click، pop) أسرع. السكربت يعيد المحاولة ثلاث مرات ثم يتوقف برسالة واضحة؛ عندها جرّب كلمة أخرى أو `--limit` أصغر، أو استعمل `synth_sfx.py`، ولا تعطّل المشروع بانتظاره.

## أين توضع المؤثرات
`story.js` يبنيها من `style.json` ومن طابع كل مقطع:
| الحدث | المفتاح في `style.json` | التوقيت |
|---|---|---|
| انتقال بين لقطتين | `sfx.transition` | قبل الانتقال بـ 0.08 ث (ذروة whoosh تأتي متأخرة) |
| مقطع بطابع حماس | `sfx.emphasis` | مع ظهور نصه |
| ظهور نص أي مقطع آخر | `sfx.text` (يفضَّل `null`) | مع ظهور نصه |

اضبطها بحسب المرجع: إن لم يكن فيه مؤثر مع الانتقالات فاجعل `sfx.transition` قيمة `null`. المؤثرات تخدم الصوت ولا تنافسه: `sfx.gain` بين −14 و−8 dB عادة.

صيغة الإشارة لأي مشهد آخر: `{ at: 1.25, sound: 'pop', gain: -6 }`، و`sound` اسم الملف بلا امتداد في `sfx/`.

## الخلط
```bash
python "<skill>/scripts/mix_audio.py" exports/video-preview-v1.mp4 --out exports/video-preview-v1-mix.mp4
```
- يضع التعليق والمؤثرات في أوقاتها، ويضبط العلو الكلي إلى −14 LUFS مع ذروة لا تتجاوز −1.5 dBTP.
- `--music music/bed.mp3 --music-gain -20` لموسيقى من المستخدم تنخفض تلقائيًا تحت التعليق.
- يطبع العلو والذروة المقاسين. القياس لا يعني أن التعليق واضح أو أن المؤثرات مسموعة؛ اطلب من المستخدم الاستماع.

## نسب الحقوق
- مؤثرات CC0 وPDM: لا نسبة مطلوبة، والسجل محفوظ.
- CC BY: انسخ أسطر `sfx/CREDITS.md` إلى وصف المنشور أو نهاية الفيديو.
- المولّدة بـ `synth_sfx.py`: بلا قيود.
- التعليق الصوتي: حسب شروط الأداة التي ولّدته؛ ذكّر المستخدم بمراجعتها قبل النشر التجاري.
